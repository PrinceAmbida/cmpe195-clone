TransportLayer - Import Guide

1. Use Unity 2022.3.62f3.
2. Install URP 14.0.12, Input System 1.7.0 and TextMesh Pro 3.0.7 in Package Manager before import.
3. Import TransportLayer.unitypackage using Assets > Import Package > Custom Package.
4. Open Assets/Scenes/TransportLayer.unity.
5. Keep Active Input Handling set to Both. The scene uses InputSystemUIInputModule with default UI actions.
6. Find the buttons under Canvas/FactPanel/LevelNavigation. RESTART LEVEL, NEXT LEVEL and LEVEL MENU have no actions.
7. Add your button actions in the Inspector. Reset Time.timeScale to 1 before leaving a finished level.

Game size: 1200 x 700. Run Tools > Transport Network Layers > Set Game Size to 1200 x 700 in your target project.
Music volume: 15%. Music credits: Assets/Resources/LayerMusic/CREDITS.txt.
Keep shared file paths and .meta files when importing both levels.
Full gameplay and a clean import into the team's menu project have not been tested.
