This folder stores the proof of concept game for each layer.
The finalized game can combine these levels into one application.
For each level, the game ideas based on threats are:
Application - Exploit
Presentation - Phishing (Padmavathy currently working on)
Session - Hijacking
Transport - Denial of Service (DoS)
Network - Man-in-the-Middle
Data Link - Spoofing (Padmavathy also working on)
Physical - Sniffing (Padmavathy also working on)
